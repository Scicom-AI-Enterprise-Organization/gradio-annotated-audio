# gradio-custom-audio

This repo contains `AnnotatedAudio`, a Gradio custom component: a drop-in replacement for
`gr.Audio` that adds a speaker lane, configurable annotation lanes (point markers and time
ranges), and a synced, click-to-seek transcript panel under the waveform.

The component, its docs, and its demo app all live in [`annotatedaudio/`](annotatedaudio/README.md).
Start there for installation instructions and usage examples.
